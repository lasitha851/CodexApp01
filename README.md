# Income & Expense Tracker

This project is a lightweight, framework-free frontend. If you see a **"Not Found"** page, it usually means the static site isn't being served from this folder.

## Run locally
From the repository root:

```bash
python -m http.server 8000
```

Then open:

```
http://127.0.0.1:8000/index.html
```

The app is a single-page HTML/CSS/JS build, so any static file server will work.
